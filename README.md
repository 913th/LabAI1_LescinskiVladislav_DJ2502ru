## Обзор

Проект реализует систему поведения врагов на основе конечных автоматов. Базовый набор состояний:

```
Idle / Patrol / Chase / Attack / Search / Death
```

Для второго типа врага (телепортирующегося) автомат дополняется состоянием **Teleport**.

## Типы врагов

### Обычный враг

### Телепортирующийся враг

Расширяет базовый автомат состоянием **Teleport**.

#### Teleport — телепортация

При выполнении определённого условия враг прекращает обычное перемещение и телепортируется в новую позицию.

Возможные условия перехода в состояние Teleport (выбирается и обосновывается студентом самостоятельно):

- игрок находится слишком далеко;
- игрок пытается убежать;
- способность готова;
- NPC потерял игрока;
- игрок находится в выгодной для атаки позиции.

После телепортации NPC продолжает выполнение своего обычного поведения.

## Обнаружение игрока

Параметры сканирования:

- угол обзора — **360°**;
- радиус обнаружения — **1 метр**;
- периодичность сканирования — задаётся студентом самостоятельно.

Если во время сканирования игрок оказывается в радиусе действия и доступен для обнаружения, NPC фиксирует игрока и переходит к преследованию (`Chase`).

## Телепортация

Телепортирующийся враг периодически получает возможность телепортироваться. Ограничения способности:

- время перезарядки;
- максимальная дистанция;
- точка назначения;
- запрет на телепортацию внутрь препятствий.

При необходимости добавляется визуальный эффект телепортации.

## Конечный автомат

Минимальный набор состояний и переходов:

| Текущее состояние | Условие                      | Следующее состояние |
| ------------------ | ----------------------------- | -------------------- |
| Patrol              | Игрок обнаружен                | Chase                |
| Chase               | Игрок в радиусе атаки          | Attack               |
| Chase               | Игрок потерян                  | Search               |
| Search              | Игрок обнаружен                | Chase                |
| Search              | Игрок не найден                | Patrol               |
| Attack              | Игрок вышел из радиуса атаки   | Chase                |
| Chase               | Доступна телепортация          | Teleport             |
| Teleport            | Телепортация завершена         | Chase                |

> Остальные переходы (например, `Idle → Patrol`) студент определяет самостоятельно, с указанием условия для каждого перехода.

Для каждого типа врага должна быть разработана отдельная схема конечного автомата:

1. Схема для обычного врага (`Idle → Patrol → Chase → Attack`, `Chase → Search → Patrol`).
2. Схема для телепортирующегося врага (базовая схема + состояние `Teleport`).
